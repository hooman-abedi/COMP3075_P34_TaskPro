# TaskPro — COMP3074 Final Project UI

A Kotlin + Jetpack Compose Reminder & Task Manager starter project.

## Included
- Home dashboard and progress summary
- Task list with filters
- Add/edit task form
- Task details, completion and delete
- Calendar-style schedule screen
- Settings screen
- Bottom navigation and floating add button
- Room database (Task entity, DAO, database, repository)
- ViewModel and Material 3 styling

## Open in Android Studio
1. Extract the ZIP.
2. In Android Studio, choose **Open** and select the `TaskPro_COMP3074` folder.
3. Use JDK 17 and allow Gradle to sync.
4. Run on an Android emulator or device.

## Notes
- Package: `com.example.taskpro`
- Minimum Android version: API 26
- Task due date and time fields currently use editable text for a simple starter UI.
- This starter includes local Room persistence, but no sign-in, cloud sync, or scheduled notification worker yet.
- Calendar screen is a UI prototype; date matching is intentionally basic and can be improved for the final submission.
- Update the greeting, project details, and sample content to reflect your team.
